# Telegram Notifier Scoop bucket

Official Scoop bucket for the [AgentForge Telegram Notifier standalone CLI](https://github.com/AgentForge-Labs/telegram-notifier-distributions).

## Install

```powershell
scoop bucket add agentforge-telegram-notifier https://github.com/AgentForge-Labs/scoop-telegram-notifier
scoop install agentforge-telegram-notifier/telegram-notifier
telegram-notifier version
```

Download manifests point to the official publicly downloadable Windows amd64/arm64 version 0.1.0 zip archives with exact SHA-256 checksums published in the release. This is an independent, self-hosted Scoop bucket; a ScoopInstaller/Main inclusion is not claimed. CI execution on a real Windows/Scoop installation remains to be verified.
